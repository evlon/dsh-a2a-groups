# 成员状态机

> 一个人和一个群的关系，只有六种状态。其中两种是**分歧状态**，需要收敛。
>
> 这份文档说明每种状态怎么产生、怎么发现、怎么收敛，以及为什么有些方向物理上做不到。

---

## 一、两个真相源

```
本地  $DSH_HOME/a2a/memberships.json     我记的
服务端 groups.json → members[]            宿主记的
```

**两个文件都可能互相不知道对方变了。** 网络断了、宿主重启、进程换数据目录，都会造成分歧。

**关键不对称**：`personKey`（成员凭证）**只存在于本地**。它入群时发一次，之后不存在于任何其他地方。

> 这一条决定了所有收敛方向的可行性。

---

## 二、六种状态

| # | 状态 | 本地记录 | 宿主成员 | 能做什么 |
|---|---|---|---|---|
| **1** | 未入群 | 无 | 无 | 稳定态 |
| **2a** | 已入群 · 无会话绑定 | 有 | 有 | 能收消息，面板看不到（没有会话可显示） |
| **2b** | 已入群 · 有会话绑定 | 有 + sessionId 匹配 | 有 | **完整可用** |
| **3a** | **宿主已删我，本地还在** | 有 | 无 | 发言失败；`unreachableAt` 标记 |
| **3b** | **本地已删我，宿主还在** | 无 | 有 | 宿主仍视我为成员，但我不可能再说话 |
| **4** | 离群待确认 | 有 + `leavingAt` | 有 | 等重试 |

## 四、收敛规则

### 3a：宿主已删我，本地还在 → 自动收敛

**怎么发现**：任何一次群操作返回 `not_member` 或 `unknown_group`

**收敛方式**：标记 `unreachableAt`，**保留凭证**

**为什么保留**：宿主换数据目录、网关抖动都会产生同样的错误。删了凭证就再也回不去。

**自动恢复**：下一次成功调用清除标记

```js
// tool-runtime.js reapStaleMembership()
identities.upsert({ ...existing, unreachableAt: Date.now() });   // 不是 remove
```

### 3b：本地已删我、宿主还在 → **只能避免，不能修复**

**怎么产生**（历史上）：`group/leave` 只删本地记录，从不通知宿主

**为什么不能修**：`personKey` 只在本地那条记录里。删了它，**没有任何东西能向宿主证明「我就是那个成员」**。

**所以唯一正确顺序是**：

```
1. 带凭证请求宿主移除我
2. 成功 → 才删本地记录
3. 失败 → 保留记录 + 标记 leavingAt
```

> 现在已经这样实现了（`a2a_group_leave` 工具）。但**历史上已经产生的 3b 无法自动修复**，只能让群主 `a2a_group_remove` 掉那条幽灵成员。

### 4：离群待确认 → 重试收敛

**怎么产生**：发起离开但宿主不可达

**记录**：`leavingAt` 时间戳

**收敛方式**：再次调用 `a2a_group_leave` 会用**同一凭证**重试

**幂等性**：第二次调用不会说「你已经离群了」，而是重试宿主

---

## 五、幂等性：哪些操作安全重试

| 操作 | 幂等 | 说明 |
|---|---|---|
| `a2a_group_join` | ✅ | 同 `personId` 重入 → 复用身份，重签凭证 |
| `a2a_group_leave`（本地群） | ✅ | 无成员 = 已离群 |
| `a2a_group_leave`（远程群） | ✅ | 无本地记录 = 已离群；有 `leavingAt` = 重试 |
| `a2a_group_post` | ❌ | 重复发就是两条消息（按 `msgId` 去重由调用方负责） |
| `a2a_group_invite` | ❌ | 每次签发**新的**一次性令牌 |

> **注意 `invite` 不幂等**：重试会产生两个有效链接，只有一个会被用掉。这是有意的——撤销一个不影响另一个。

## 六、2a：已入群但没有会话

**为什么会这样**：`memberships.json` 的键是 `(sessionId, groupId)`。如果一个会话从没被绑定，面板就不知道往哪显示。

**表现**：能收消息、能发言，但面板看不到这个群。

**收敛方式**：在会话里调一次 `a2a_group_info`，会写回绑定。

**不是 bug**：一个 DSH 可以有多个会话，同一台机器上两个会话可以是两个不同成员。

## 七、状态查看与修复

### 看当前状态

```bash
cat $DSH_HOME/a2a/memberships.json
```

| 字段 | 含义 |
|---|---|
| 有 `leavingAt` | 状态 4，重试 `a2a_group_leave` |
| 有 `unreachableAt` | 状态 3a，等下一次成功调用自动清除 |
| 都没有 | 状态 2a / 2b |
| 没有这个群的记录 | 状态 1，或**状态 3b**（危险） |

### 判断是不是 3b

```
本地没有记录，但宿主 group_info 显示你在成员里
```

**怎么修**：让群主 `a2a_group_remove` 掉你。你自己已经没有办法了。

### 预防 3b

**永远不要手动删 `memberships.json` 里的条目。** 用 `a2a_group_leave`。

---

## 八、为什么不能「服务端跟随本地」

这是设计上唯一做不到的收敛方向，值得单独说明：

**「我想退出」这个意图，必须带着凭证到达宿主。**

而执行「删掉我」的动作本身会销毁那个凭证。所以：

```
先删本地 → 凭证没了 → 意图永远到不了宿主 → 3b
先问宿主 → 成功 → 删本地 → 状态 1（正确）
        → 失败 → 保留 + 标记 → 状态 4（可重试）
```

**没有第三条路。**
