feat: the panel can write to the Host, over DSH's own Connection RPC

The panel needed a write path that does not drag the user into a Session. It has one: a channel on DSH's
Connection transport, called from the browser through `ctx.connection.rpc`.

Verified end to end over HTTP with the documented envelope:

    POST /a2a-panel/ping
    { "type": "client-request", "rpcId": "...", "method": "ping", "payload": { ... } }

    -> {"ok":true,"value":{"pong":true,"at":1793776928558}}
    -> {"ok":false,"error":{"code":"not_found",...}}      for an unknown endpoint

FOUR THINGS I HAD WRONG

1. `ctx.connection.rpc.handle()` was the right call, but from the plugin's own fiber it hits the known
   upstream bug (#8414): registration runs an effect on a fiber that lacks the declaration and throws
   `cannot get property "webServer" without inject`. The discussion notes the ROOT context is unaffected;
   registering through `ctx.root` works, and that is what this does.

2. The browser half is NOT `createWebConnectionRpc` — that name is internal. The module's real exports are
   `{ RpcId, apply, inject, installConnection, transportError }`: it is a plugin, and what it publishes is
   the `connection` service. The call is `ctx.connection.rpc.call(channel, endpoint, payload)`, the exact
   mirror of the Host's `handle`.

3. `dsh.client.inject` is the module table, not a service list — a package can only `require` what it
   declares there. Ours listed only `slots`, which is why the first attempt reported "module 未能加载".

4. A raw POST is 405 because the transport carries a `ClientRequest` envelope, not a bare body.

WHY THIS PATH RATHER THAN A CREDENTIAL IN THE PAGE

The write happens in the Host process, where the ledger holding the member credential lives. The credential
never leaves, there is no second authentication scheme, and Connection already authenticates the request. A
panel carrying a member key would hand every group's credential to anything that can read the DOM.

STILL TO DO

The `profile` endpoint's handler is in place (it calls `groups.setProfile`, `groups.setPersonProfile`, or

The temporary self-check button has been removed now that it has done its job — it was a probe, and a probe
